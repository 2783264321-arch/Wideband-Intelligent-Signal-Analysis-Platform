# 使用指南

本指南介绍 WISA 的主要任务工作流程，面向使用者而非开发者或 API 调用方。

## 分析单个 IQ 文件

打开 **数据管理**，选择一个独立样本，点击 **分析**。选择算法流水线，执行环境保持
**自动选择**，然后点击 **运行**。频谱工作台会显示检测结果，并在可用时显示真值标注（GT）。

## 分析数据集

打开 **数据管理**，进入一个数据集，查看其样本。点击 **创建数据集实验** 即可在数据集上
运行算法流水线。数据集标识会自动带入，无需手动填写。

## 对比两条算法流水线

打开某个样本的 **检测记录**，选择两条已完成的任务，然后点击 **对比**。算法评测实验室会
带入选中的两条任务，便于查看检测差异。

## 导入别处生成的检测结果

点击 **导入检测结果**，选择分析包文件即可导入在别处生成的结果；平台会自动匹配本机的数据集与
样本，不会重新运行推理。导入的结果会出现在对应的 **检测记录** 中。
